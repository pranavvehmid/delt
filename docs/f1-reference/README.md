# F1 references

Drop screenshots (PNG/JPG) and short clips (MP4, under ~20MB each) here. Name them by kind,
e.g. `ig-grid-01.png`, `tv-grid-intro-p1.mp4`. They are only for studying the style; the folder
is gitignored for media so nothing copyrighted gets published.

Needed (the more the better, at least the starred ones):

1. ★ **Instagram profile grid**: 2–3 full-screen screenshots of the @f1 profile grid (shows palette and layout across posts).
2. ★ **Race result / starting grid posts**: 3–5 posts that list positions (P1, P2…), with team colours.
3. ★ **Driver name posts**: 2–3 posts where a driver's first name is in script and the surname in heavy bold.
4. **Stories**: 2–3 story frames (headlines, countdowns, session times).
5. ★ **TV grid announcement**: a 10–20s clip, or 4–6 frames, of the starting grid being read out (P1, P2, P3… appearing).
6. ★ **Driver lower third**: 2–3 frames of a driver's name banner on TV.
7. **Timing tower**: 1–2 frames of the live tower on the left of the TV picture.
8. ★ **Pre-race intro / bumper**: a 10–20s clip, or 6–8 frames, of the opening titles.
9. **Bold kinetic type**: 1 clip of the big animated lettering you mean (the Wispr Flow-style promo feel).
10. **Session / weekend schedule graphic**: 1 frame (useful for the Deadlines screen).

From these I'll write `docs/F1_STYLE_SPEC.md`: sampled hex values, type pairing (script + heavy),
sizes and tracking, layout rules, shapes, textures, motion timings, and colour coding.
